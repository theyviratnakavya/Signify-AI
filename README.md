# Signify AI 🤟

Signify AI is an AI-based sign language recognition project that uses computer vision and hand landmark detection to recognize hand signs through a webcam.

## Features

* Real-time hand detection
* Hand landmark tracking
* Finger position analysis
* Sign recognition
* Webcam-based interaction

## Technologies Used

* Python
* OpenCV
* MediaPipe
* Computer Vision

## How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```

## Project Goal

The goal of Signify AI is to create an accessible system that can recognize sign language gestures using computer vision and help improve communication accessibility.
